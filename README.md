初始讀者素材已建立；全書與完整章節範例仍在製作。尚未宣稱完成 Hermes／Astra 端到端實測，亦未鎖定出版適用版本。

## 從這裡開始

1. 閱讀 [入門指南](docs/getting-started.md)。
2. 完成 [筆記轉行動清單](examples/first-task/README.md)。
3. 複製 [任務規格範本](templates/task-spec.md) 設計自己的任務。
4. 查閱 [版本與測試狀態](docs/compatibility.md)、[勘誤](ERRATA.md) 與 [常見問題](docs/faq.md)。

不熟悉 Git？點選 GitHub 的 Code → Download ZIP，解壓後閱讀檔案即可。

## 閱讀路線

- 共同基礎：第一個安全任務 → 任務規格 → 驗收 → 技能保存。
- A 路線（規劃中）：研究、文件、資料整理。
- B 路線（規劃中）：程式、測試、自動化。

## 範圍與安全

公開素材不含書稿、EPUB、封面原檔、個人文件或憑證。示範資料均為虛構。
請勿上傳 API key、登入 token、私人日誌或未去識別的資料。範例從唯讀輸入、新建輸出開始；刪除、發布、寄信與付費操作需另行確認。
