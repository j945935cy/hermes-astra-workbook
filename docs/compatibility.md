# 版本與測試狀態

PM 修訂配套，對應校閱版 v4。Happy eBook Authors。發布以 GitHub 的固定標籤 `review-v4` 為準；main 為持續更新版。

## 基準與可重跑命令

讀者基準 Windows＋WSL2／Bash、Python 3.11 以上。本輪確定性測試實際使用 Python 3.14.4、Linux 6.18.33.2-microsoft-standard-WSL2。
從配套根目錄執行：

```bash
python3 -B scripts/verify_assets.py
python3 -B -W error::ResourceWarning -m unittest discover -s tests -v
```

測試只用 Python 標準函式庫。使用臨時副本、loopback HTTP，不呼叫模型、不修改 Hermes 設定、不安裝套件。不要用 `python3 -O`，章內驗收器使用 assert。

## 測試輸出怎麼讀

外層 unittest 實際執行 16 項；第 10 章的 30 個情境由其中一項再執行，不是額外 30 個 unittest 方法。全部預期拒絕的子程序非零退出，外層測試確認拒絕正確後才算通過。尚未執行的模型與外部服務測試仍明列，資產檢查 PASS 不代表端到端通過。
