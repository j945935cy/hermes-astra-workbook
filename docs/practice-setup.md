# 練習副本準備與停止條件

## 配套副本主線：先準備，再工作

適用 Windows＋WSL2 的 Bash；不是 PowerShell。先依第 2 章確認 Python 與帳務／資料權限。正式配套版本：**待主編固定**。`main` 是更新版；固定前僅使用主編指定的相符修訂快照，勿把歷史基準當成本輪正式配套。

分清楚兩個位置：**workbook 根目錄只供準備素材；新練習目錄才執行任務與驗收。** 根目錄應看得到 `scripts/prepare.py` 與 `extraction-manifest.json`。以下假設你已把相符配套放在 `$HOME/hermes-astra-workbook`；若下載在別處，只更換第一個 `cd` 的位置，不更換成練習目的地。用 WSL 路徑，不把 Windows 的 `C:\` 寫法直接貼進 Bash。

先單獨切到配套根目錄：

```bash
cd "$HOME/hermes-astra-workbook"
```

只有 `cd` 成功且確認是配套根目錄，才執行本章 prepare。下面以第 3 章為例；其他章使用該章明列的章號與全新目的地。**不要先 mkdir 目的地**，也不要使用已有目錄：

```bash
python3 scripts/prepare.py 3 "$HOME/hermes-first-task"
```

只有命令成功結束、看到 `READY:` 及正確目的地，才另外執行下一段。不要一次貼完所有區塊，因為上一段失敗不會阻止另一段的 `cd`。

```bash
cd "$HOME/hermes-first-task"
pwd
```

確認 `pwd` 是剛才的新練習目錄，才照章內指示啟動 Hermes 或驗收。prepare 只複製起始素材，不呼叫模型、不產生答案；第 3／18 章預建的空 `output` 目錄不是完成產物。不要在 workbook 原檔上跑任務。

## READY 與 STOP

- **READY 是素材已準備，不是任務通過。** 執行模型與人工驗收是後面的工作。
- **STOP、非零結束或任何錯誤：先停，不往下一個區塊走。** 目的地已存在時保留它，辨認是否有成果；重做改用另一個尚不存在的目錄名稱，prepare 與後續 `cd` 必須一起改。不要刪檔解鎖、加入覆寫參數或重跑手動建檔蓋掉舊成果。
- 素材與清單不符、來源缺少或父目錄不合法：不要手改雜湊、清單或驗收器讓它過關。核對配套版本並保留錯誤訊息求助。中途失敗可能留下部分副本，不能視為 READY，也不可直接在該目錄繼續；保留現場另選新目的地。
- 任務中發現輸出已存在、來源矛盾或要求越權：依章內停止規則停止全部或受影響部分，記下未決項。不要把檢查素材通過當成覆寫或發布授權。

## 手動建檔只作選做

選做用另一個全新目錄，從章內完整素材開始，不先 prepare 再貼手動區塊；已 prepare 的讀者跳過手動建立素材段。若章內使用 `mkdir ... && cd ...`，`&&` 代表前項成功才執行後項；不要改成 `mkdir -p` 讓已存在目錄也放行。

對照檔名與內容後才開工；章別的原始空白、CSV 欄位、來源／瀏覽器設定檔差異，以及排程 tick 的影響範圍仍須讀。這張卡不取代各動作旁的特有風險提醒，也不會自動隔離工具權限。求助只貼虛構最小案例與已去識別錯誤，不貼秘密。
