## schedule-draft.md 維運附頁

業務規則：T02/T03，T03 負責人待確認，不補日期。工作狀態：尚未註冊／尚未執行／通知未設定；local、暫停、一次額度。素材完整路徑：待填；時區／下一次時間：待確認。

| 角色 | 姓名／替代人／非秘密聯絡方式 | 檢查時點與停止權 |
|---|---|---|
| 工作流負責人 | 待填 | 每次改版前；停整條流程 |
| 素材維護者 | 待填 | 預定執行前；缺來源阻擋本期 |
| 結果審核者 | 待填 | 到期後與交付前；退回成果 |
| 主機／gateway 看守者 | 待填 | 執行前後與離席前；停練習工作 |
| 收件目標核准者 | 待填 | 初次或目標變更前；停通知 |
| 失敗接手者 | 待填 | 延遲超標時；停止重試、人工替代 |

可接受延遲／本次截止：待批准；重試上限：待批准，未批准即零次；過期輸出標「來源時間、非本次結果」；人工替代交付：已審本機檔。角色可兼任，無替代人就不批准本人離席的無人值守。T03 待確認是業務資料，不是維運授權。

| 故障 | 證據 | 處置 |
|---|---|---|
| 睡醒沒有本次輸出 | 本工作 runs／時間／主機紀錄 | 看守者查漏跑；到截止由接手者人工，不新建重複排程 |
| 模型失敗 | 錯誤／部分結果 | 負責人確認副作用後准有限新輪重試，上限到停 |
| 本機成功、通知失敗 | 既有已驗收檔／交付設定／接收端 | 核准者優先人工交付，不重跑生成鏈 |
| 投遞未知 | 同一目標的收送證據 | 不當成功，不盲目重送；截止交人工查核 |

四級判定：草稿通過（人核對）→本機單次通過（真實 ID 與產物）→私人通知通過（目標與內容讀回）→定期運作待核准（自然到期、時區讀回、認證、在線、失敗、停用演練）。後三級教材仍待測。手動 tick 不算自然到期。未通過就退到前級；這是人工工作規則，非內建自動重送承諾。
