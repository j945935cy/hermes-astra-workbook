# 排程草稿任務（手寫，不註冊）

建立 schedule-draft.md：填本次 tasks.md 完整路徑、只選進行中與未開始、保留 ID 與未知負責人、local、暫停、一次額度、時區待確認、停止方式。
狀態分列：尚未註冊／尚未執行／通知未設定。不得啟動模型或 gateway，不建立 profile。

同時依 management-lab.md 補工作流負責人、素材維護者、審查者、主機／gateway 看守者、收件核准者、失敗接手者與替代人，逐項填時點、聯絡方式、停止權；再填可接受延遲、截止、重試上限、過期標示與人工替代。演練漏跑及本機成功而通知未知。只有草稿即合格；缺責任人不能批准無人值守，手動觸發不等於自然到期。
