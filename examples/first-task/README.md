# 第一個任務：筆記轉行動清單

難度：入門。使用虛構資料，不需外部服務憑證以外的工作帳號。模型可能產生費用或消耗訂閱用量；不提供完成時間保證。

## 起始狀態

以本 repo 作為 Hermes 工作目錄，確認 `examples/first-task/notes.md` 存在，且 `output/action-items.md` 尚不存在。若輸出已存在，請另選新路徑，不覆寫舊檔。

## 交給 Hermes 的任務

> 讀取 examples/first-task/notes.md，僅根據該檔建立 output/action-items.md。輸出 Markdown 表格，欄位為任務、負責人、期限、來源編號。未提供的資訊寫「待確認」，不要自行猜測日期或負責人。另列未決議事項，區分提案與已指派工作。每一項均保留來源編號。只能讀取輸入與新增輸出，不修改來源、不連網、不寄信、不刪除檔案；輸出已存在就停止並詢問。完成後說明寫入位置及尚待確認的資訊。

## 驗收

自行開啟輸出，與 [驗收基準](expected.md) 對照。措辭可不同，事實不可變更。

## 失敗情境

- 來源不存在：應回報缺少檔案，而不是自行編造會議。
- 再次執行且輸出存在：應停止，不覆寫。
- 資訊不足：應標示待確認，不自行補上姓名或期限。

以上為待執行的測試情境，不是已通過測試的宣告。
