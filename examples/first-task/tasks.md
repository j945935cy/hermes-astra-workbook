# 任務範本（貼入對話，不是 Shell）

人工後續練習見 [N4 待確認交接與退回版](handoff-example.md)；不將其假設批准當成當次授權。

> 讀取 examples/first-task/notes.md，僅根據該檔建立 output/action-items.md。輸出 Markdown 表格，欄位為任務、負責人、期限、來源編號。未提供的資訊寫「待確認」，不要自行猜測日期或負責人。另列未決議事項，區分提案與已指派工作。每一項均保留來源編號。只能讀取輸入與新增輸出，不修改來源、不連網、不寄信、不刪除檔案；來源缺失或輸出已存在就停止並詢問，不另找來源、不覆寫或換名。完成後說明寫入位置及尚待確認的資訊。
