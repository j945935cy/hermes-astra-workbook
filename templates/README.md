# 概念章與共用範本

## 起始狀態

Windows＋WSL2／Bash、Python 3.11 以上；目前目錄是配套根目錄。這些是紙筆／編輯器練習，不需要登入或模型。新筆記檔名不得與既有檔案衝突。

## 精確命令

```bash
python3 -B scripts/verify_assets.py
python3 -B -m unittest discover -s tests -v
```

預期 PASS／16 項 unittest 通過；這是固定素材驗證，不替你填寫表格。用文字編輯器開啟對應範本，另存到自己明確選的新檔，已有同名就停止。

## 預期產物

- [第 1 章工作單](ch01-task.md)：唯一輸入、產物、授權、停止、驗收條件。
- [第 2 章環境卡](ch02-task.md)：不填秘密，版本與連線結果分開。此範本不執行安裝、登入或連線；未觀察欄位保持未驗證。
- [第 5 章授權單](ch05-task.md)＋[M1–M3 虛構摘要](ch05-messages.md)：分類／下一步／誰確認；成本保持未量測。
- [一般任務規格](task-spec.md)：填自己的新任務，不混入憑證。

## 正向測試

第 1 章未知期限可留待確認；第 2 章程式存在與模型能回應分成兩關；第 5 章 M1 只可擬稿、M2 待有權人決定、M3 不下載登入。

## 負向測試

工作單只寫「整理得專業」不通過；版本成功卻把認證未測寫成成功不通過；擅自寄信／接受報價、填入虛構帳單金額不通過。這些是人工判準，不是已做的外部操作。

## 未驗證界線

完整安裝、模型連線、費率與授權工具行為不在本範本測試內；使用者完成觀察前不要改成已驗證。其他平台未測。
